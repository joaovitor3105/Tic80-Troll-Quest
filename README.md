## 📖 Sobre o Projeto

**Troll Quest** é um jogo 2D estilo *rage game* que vai testar sua paciência, reflexos e capacidade de rir das próprias frustrações! Desenvolvido no **TIC-80** utilizando **Lua**, o jogo apresenta armadilhas traiçoeiras, surpresas inesperadas e mecânicas que desafiam sua lógica e criatividade.

Este projeto foi desenvolvido como parte da disciplina **Linguagens de Programação** do 4º semestre do curso de **Engenharia de Computação** do **CEFET-MG**.

---

## ✨ Características

- 🎯 **Desafios trolls**: Armadilhas criativas e surpresas que vão te pegar desprevenido
- 🎨 **Arte pixelada**: Gráficos no estilo retrô 8-bit
- 🎵 **Trilha sonora**: Sons e músicas nostálgicas criadas no TIC-80
- 🕹️ **Controles simples**: Fácil de aprender, difícil de dominar
- 🏆 **Níveis progressivos**: Cada fase é mais desafiadora (e frustrante) que a anterior
- 💀 **Morte instantânea**: Um erro e você volta ao início... ou quase!

## 🎮 Como Jogar

### Requisitos

- **TIC-80** instalado em seu sistema ([Download aqui](https://tic80.com/))

### Instalação

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/troll-quest.git
cd troll-quest
```

2. Abra o TIC-80

3. Carregue o jogo:
```lua
load troll-quest.tic
run
```

### Controles

| Tecla | Ação |
|-------|------|
| ⬅️ / ➡️ | Mover para esquerda/direita |
| Z | Pular |
| ESC | Menu/Pause |

## 🎯 Objetivos do Jogo

- 💎 Colete todos os itens espalhados pelos níveis
- 🚪 Encontre a saída de cada fase
- ⏱️ Sobreviva às armadilhas trolls
- 🧠 Use a criatividade para superar obstáculos impossíveis
- 😤 Mantenha a calma (boa sorte com isso!)
